# 示例词库（UTF-8），可修改后通过应用内「导入词库」导入
# 三种写法：
#   单词一行            → 输入前缀联想该单词
#   键 值（空格分隔）    → 输入 key 前缀候选 value
#   键 TAB 值 TAB 词频   → 词频越大越靠前

# 英文示例
hello
world
wear
keyboard
android
